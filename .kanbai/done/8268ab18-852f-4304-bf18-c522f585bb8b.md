Cards created via `kanbai add` should always land in backlog. The `--lane` / `-l` option allowed bypassing this, letting agents or humans create cards directly in in_progress, review, or done.

---
**Fixed 2026-06-22 00:13**
- **Understood:** The `add` CLI command had a `--lane` option that defaulted to backlog but could be overridden, which breaks the expected workflow where new work always enters the board at backlog.
- **Encountered:** No edge-cases; straightforward removal.
- **Fixed:** Removed the `--lane` parameter from `commands.add()` and hardcoded `lane="backlog"` in the `create_card()` call.

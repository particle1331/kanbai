When creating a card the agent should infer sensible defaults for all optional fields
(priority, epic, tags, and a DoD-style description) from the card title and current
board context, rather than leaving them blank or requiring the user to supply them.
The user can still override any field explicitly when they want control.

Acceptance criteria:
1. The system prompt explicitly instructs the agent to infer priority, epic, tags, and
   a concise DoD-style description whenever the user does not supply them.
2. The agent picks the most contextually appropriate epic from the existing epics on
   the board rather than defaulting to Unassigned.
3. Cards created via a short, hurried message still get a meaningful description and
   correct metadata.

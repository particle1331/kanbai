title: Board does not auto-refresh when cards are modified via MCP
updated_at: '2026-06-21T18:45:16.017783+00:00'
---

When cards are created, moved, or updated via the MCP server, the board UI does not automatically repaint. The file watcher fires and syncs data correctly, but `_on_external_change()` in app.py was missing a `page.update()` call after `on_board_change()`. The user had to trigger a UI interaction (e.g. switching epics) to force a redraw.

Fix: add `page.update()` at the end of `_on_external_change()`.

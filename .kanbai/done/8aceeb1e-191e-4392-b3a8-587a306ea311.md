title: Agent should comment on card with fix summary after resolving
updated_at: '2026-06-21T18:45:14.315846+00:00'
---

After an agent works on a card, it should append a timestamped section to the card description (not a comment — comments are plain text; description renders Markdown) summarising: what it understood the issue to be, any problems it encountered, and how it fixed it. This gives reviewers a clear audit trail without reading the diff.

Format to append:
```
---
**Fixed [YYYY-MM-DD HH:MM]**
- **Understood:** <what the issue was>
- **Encountered:** <any problems or edge-cases>
- **Fixed:** <what was changed and why>
```

## Summary
Automatically append structured comments when agents (or the system) modify a card, creating a full audit trail without requiring agents to manually journal.

## Implementation

### System comments (operations.py)
- New comment role: `system` — auto-generated, not authored by human or agent
- Trigger auto-comments on these operations:
  - **move_card**: "Moved from {old_lane} → {new_lane}"
  - **update_card** (field changes): "Updated priority: medium → high" / "Added tag: bug"
  - **add_file_ref**: "Associated file: src/foo.py"
  - **toggle_checklist_item**: "Completed: Implement storage layer ✓"
  - **link_cards**: "Linked to #12 (blocks)"
  - **archive_card**: "Archived"
  - **unarchive_card**: "Restored from archive"

### Storage
- System comments stored as regular comments with `role: system`
- Visually distinct from human/agent comments (muted styling)
- Can be hidden/shown via toggle in UI

### UI (card_dialog.py)
- System comments rendered in muted grey, smaller font, no bubble
- Timeline-style: icon + one-line summary + timestamp
- Toggle: "Show system activity" (default on, rememberable)
- Interleaved with human/agent comments chronologically

### Settings
- Global toggle: "Auto work log" on/off (default on)
- Per-card toggle not needed (keep it simple)

### Dependencies
- Requires typed comments (#50) to be implemented first for the role field
- Builds naturally on the comment infrastructure

## Summary
Structured subtask tracking within a card. Agents check off items as they complete them, giving granular progress visibility.

## Implementation

### Storage (models.py / markdown_store.py)
- New field on Card: `checklist: list[dict]` where each item is `{text: str, done: bool}`
- Markdown format: use GitHub-style task lists in the description body for portability:
  ```
  - [ ] Implement storage layer
  - [x] Add MCP tool
  - [ ] Update UI
  ```
- Parse `- [ ]` / `- [x]` lines from description into structured checklist
- Round-trip: when saving, re-render checklist items back into markdown task list syntax
- Keep checklist items ordered by their position in the description

### MCP (server.py)
- `add_checklist_item(card_id, text, position?)` — append or insert item
- `toggle_checklist_item(card_id, index)` — mark done/undone
- `remove_checklist_item(card_id, index)` — delete item
- `get_checklist(card_id)` — returns [{text, done, index}]
- Include checklist in `get_card()` response with completion stats (3/5 done)

### UI (card_dialog.py)
- Render checklist as interactive checkboxes in card dialog
- Click to toggle done state
- Add item inline (text field + enter)
- Drag to reorder (stretch goal)
- Show completion bar: "3/5 tasks" with progress indicator

### Health integration (health.py)
- New signal: cards in_progress with 0% checklist completion for >2 days
- Optional: track checklist velocity (items checked per day)

## Acceptance criteria
- [ ] Card model supports checklist field
- [ ] Markdown `- [ ]` / `- [x]` round-trips correctly
- [ ] MCP tools: add, toggle, remove, get checklist
- [ ] UI renders interactive checkboxes
- [ ] get_card includes checklist + completion stats

## Summary
Link specific files and code locations to a card so agents immediately know what code is relevant when picking up work.

## Implementation

### Storage (models.py / markdown_store.py)
- New field on Card: `file_refs: list[str]`
- Format: relative paths with optional line ranges: `"src/kanbai/ui/board_view.py"`, `"src/kanbai/board/health.py:46-80"`
- Markdown storage: store in frontmatter as a list:
  ```yaml
  file_refs:
    - src/kanbai/ui/board_view.py
    - src/kanbai/board/health.py:46-80
  ```
- Validate paths are relative (no absolute paths)

### MCP (server.py)
- `add_file_ref(card_id, path, start_line?, end_line?)` — attach a file reference
- `remove_file_ref(card_id, path)` — detach
- `get_file_refs(card_id)` — list all refs
- Include in get_card response and get_card_context bundle
- Agents can also set file_refs via update_card

### UI (card_dialog.py)
- "Files" section in card dialog showing referenced paths
- Monospace font, file icon prefix
- Add ref via text input (with path autocomplete — stretch goal)
- Remove ref via X button

### Agent workflow
- When agent creates or picks up a card, it can attach relevant files
- When agent finishes, file_refs serve as documentation of what was touched
- Other agents picking up related cards can immediately find relevant code

## Acceptance criteria
- [ ] Card model has file_refs field
- [ ] Markdown frontmatter round-trips file_refs
- [ ] MCP tools: add, remove, get file refs
- [ ] UI displays file refs in card dialog
- [ ] Paths validated as relative

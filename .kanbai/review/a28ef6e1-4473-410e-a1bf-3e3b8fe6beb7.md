## Overview

Surface the existing event_log as a visible "Recent Activity" panel in the UI, giving users and agents a timeline of what happened on the board without needing git log.

## Plan

### Phase 1: Core feed component
- Read from event_log storage (already captured: creates, moves, updates, archives)
- Build a scrollable timeline widget showing: timestamp, action type icon, card title (clickable), actor (user vs agent), and a 1-line summary
- Cap at last 50 events by default, with "load more"

### Phase 2: Filtering & scoping  
- Filter by epic (inherit current epic filter from board)
- Filter by action type (moves, creates, comments, etc.)
- Filter by actor (human vs agent)

### Phase 3: Card-level timeline
- Show per-card activity in the card dialog (history tab or collapsible section)
- Include: lane transitions, field changes, comments added, links created

### Phase 4: Agent context
- Expose via MCP tool: get_activity_feed(epic?, card_id?, limit?)
- Agents can ask "what changed today?" or "what happened to card X?"

## Notes
- Event log already stores structured data — this is mostly a UI + MCP exposure task
- Keep the panel lightweight (lazy-load, don'''t block board render)
- Consider a subtle notification dot on the nav icon when new activity arrives
